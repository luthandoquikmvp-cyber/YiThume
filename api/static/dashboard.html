Security note
Do not put Stripe secret keys in HTML. Live mode should use server-created Stripe Checkout sessions (redirect URL returned by backend).
Mode
Switch to Live (Stripe)
Live mode enables Stripe Checkout on the storefront. Safer pattern: the backend creates Checkout sessions.
Safe Stripe rule: No secret keys in the browser. The storefront calls your backend, backend calls Stripe, backend returns a checkout URL.
Stripe settings (stored server-side)
Backend endpoint expected: POST /v1/store/<store_id>/mode with JSON like: { mode: "live", stripe: { publishable_key, success_url, cancel_url } }
